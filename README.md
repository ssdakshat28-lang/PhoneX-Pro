# PhoneX Pro - Interactive Mobile Showcase Website

A modern, responsive showcase landing page built with React, Tailwind CSS, and Vite.

## 🚀 Live Demo
Check out the live interactive preview here: [PhoneX Pro Live Demo](https://d-phone-studio.lovable.app)

## ✨ Features
- **Hero Section:** Dynamic phone mockup with interactive color switcher (Phantom Black, Titanium Silver, Deep Purple).
- **Interactive Screen Showcase:** Switch between Camera, Gaming, Battery, and AI modes.
- **Bento Box Grid:** Sleek tech specifications highlight.
- **Pre-Order Modal:** Dynamic storage tier selector and price calculator.

## 🛠️ Tech Stack
- React / TypeScript
- Tailwind CSS
- Lucide React Icons
- Vite
